# MetalForma CNC

Sitio web para mostrar proyectos de fabricación CNC y recibir solicitudes de presupuesto.

## Tecnologías

- React
- Node.js
- Express
- MySQL

## Estructura

- `frontend`: aplicación React.
- `backend`: servidor y API.
- `metalforma.sql`: base de datos.

## Ejecución

Backend:

```bash
cd backend
npm install
npm start
